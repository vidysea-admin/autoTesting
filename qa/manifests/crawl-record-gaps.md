## Criteria

1. **(a) A same-URL layout toggle is not a new screen.** `screen_identity.is_layout_toggle`
   (`stages/screen_identity.py:48`) recognises a button/switch named collapse/expand/toggle/show/
   hide/minimise/maximise + sidebar / side nav / side panel / navigation [menu|drawer|panel|bar];
   `same_screen` (`:57`) is true when the signature is unchanged OR the pressed control is such a
   toggle and the `url_template` is unchanged. `explore_node.try_action` (`explore_node.py:169`)
   uses it, so the press records `SAME_SCREEN` with `to_node == from_node` instead of minting a node.
   `structural_signature` and node ids are deliberately UNCHANGED (no id drift for stored personas).
   Tests: `test_sidebar_toggles_are_layout_toggles` (6), `test_other_controls_are_not_layout_toggles`
   (5), `test_a_layout_toggle_does_not_create_a_screen_record`.
2. **(b) Per-screen inventory of successful API requests.** New `ApiCall(method, path, status,
   count)` (`schema/screen_graph.py:54`, `extra="forbid"`) and `ScreenNode.api_calls` (`:99`,
   default `[]`, so old `nodes.jsonl` load). `PageObserver.api_responses` / `drain_api_responses`
   (`browser/observe.py:63,111,143`) keep the XHR/fetch subset (Playwright `resource_type`);
   `network_capture.api_inventory` (`stages/network_capture.py:58`) keeps first-party, status < 400,
   not a static asset, not `/_next/`, path `url_template`'d (ids collapse), query/host dropped,
   redacted, grouped and counted, capped at `MAX_API_CALLS_PER_NODE=100`.
   `ExploreRuntime.take_responses` (`stages/explore_runtime.py:96`) drains per action into `net_log`
   (the crawl-wide NETWORK evidence still sees every response, `explore.py:210`) and attributes the
   XHR/fetch part to the screen: before an action to the screen being explored, after it to the
   destination screen (`explore_node.py:153,170`); the seed is attributed in `_seed`
   (`explore.py:155`, login traffic discarded `:143`). `explore_summary.apply_api_calls`
   (`explore_summary.py:97`, called from `_finish`, `explore.py:218`) writes them with `update_node`.
   Tests: `test_api_inventory_keeps_first_party_successes_as_method_path_status`,
   `test_api_inventory_redacts_and_is_bounded`, `test_a_crawl_records_api_calls_on_the_screen_that_made_them`,
   `test_a_node_written_before_api_calls_existed_still_loads`.
3. **(c) An errored edge records its cause.** Finding: the reason was already stored but as the
   whole multi-line Playwright call log (see the 6 `errored` edges in that crawl's `edges.jsonl`),
   unbounded and unstructured. `ScreenEdge.error_class` (`schema/screen_graph.py:124`) now holds the
   exception class (`TimeoutError`, `Error`, or `ReturnLost`); `record_edge` (`explore_node.py:70-80`)
   scrubs secrets FIRST, then collapses whitespace to one line and caps at `MAX_REASON_CHARS=400`.
   Test: `test_an_errored_edge_records_class_and_a_bounded_single_line_cause`.
4. **(d) `Crawl.provider` no longer claims "mock".** `provider: str | None = None`
   (`schema/crawl.py:255`); a `mode="before"` validator (`:279`) reads the legacy stored `"mock"`
   (the old default, not a stub judge) as `None`; any real id is kept. `explore.py` docstring
   updated; `tests/test_explore.py:60` now asserts `is None`. Nothing in `src` read `Crawl.provider`.
   Tests: `test_a_crawl_records_no_provider`,
   `test_a_real_provider_id_is_kept_and_the_legacy_mock_default_reads_as_none`.
5. **Design rules hold.** No file over 300 lines (`explore_node.py` exactly 300 after trimming the
   `capture` docstring; `explore.py` 299). No new src module, no `*_v2`. `docs/MAP.md` regenerated by
