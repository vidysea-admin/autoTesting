## What changed (edited in place; no new module, no new schema)

- src/autotester/core/image_privacy.py `_text_boxes` — a level-5 word below `MIN_CONFIDENCE` (including 0 and tesseract's -1) now adds its own box to the mask list and its line band is masked as before; the image is released. `nan` or a score above 100 still raises `uncertain_ocr`. A blank-text row below `MIN_CONFIDENCE` with valid geometry (a glyph OCR could not read) is masked too; a blank row with invalid geometry is skipped. Geometry of any non-blank word is still validated (`invalid_ocr_geometry`). No recognised text at all still raises `no_recognized_text`.
- src/autotester/core/image_privacy.py `_check_mask_area` (new private function, same module) — the union of all mask boxes may not exceed `MAX_MASK_FRACTION = 0.6` of the image, else `mask_exceeds_limit` and the image is withheld. Called from `_sanitize_one` before any pixel is drawn.
- src/autotester/core/image_privacy.py `_find_tesseract` / `_env_tesseract` (new private functions, same module) — `shutil.which("tesseract")`, then `AUTOTESTER_TESSERACT` (process env, else that one key read from the repo-root `.env` via `dotenv_values`, key name only, no value logged), then `WINDOWS_TESSERACT = C:/Program Files/Tesseract-OCR/tesseract.exe`; the first that exists wins; none -> `local_ocr_unavailable` (fail closed). `_local_ocr` calls `_find_tesseract`.
- tests/test_image_privacy.py (284 lines), tests/test_image_privacy_engine.py (141) — new tests below; the `conf=84` row left the withheld parametrization (it is now masked and released); the two tests that patched `shutil.which` to None now use a `no_engine` fixture that also blanks the Windows path, env key and repo `.env`, because the Windows install now exists on this machine.
- tests/test_run_failure_artifacts.py — fixture only: the 30x20 OCR box was made 1 px tall (band 9 of 20 rows) so it stays under the new area limit, and the "uncertain image" case now uses an impossible score (101), which is still withheld. Intent of both tests unchanged.
- docs/MAP.md — regenerated by `autotester map` (module one-line description changed).

## Criteria

- C1 mask-not-withhold: a low-confidence word is blacked out, never trusted, and the image is released; every existing secret/PII mask rule (full line bands) stays. Over `MAX_MASK_FRACTION` -> withheld.
- C2 fail-closed preserved: OCR failure, empty/blank-only recognition, impossible confidence (nan, >100), invalid geometry, engine timeout/oversize, missing engine all still withhold with a fixed reason code and no OCR text in any message.
- C3 tesseract lookup: PATH, then `AUTOTESTER_TESSERACT`, then the standard Windows path; none -> fail closed.
