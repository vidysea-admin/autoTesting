## Why the watchdog looks like this (measured, not assumed)
Playwright's sync API is thread-bound: `pw.stop()` from a second thread raised `Cannot switch to a different thread` (probe `thr.py`), so the diagnosis' "thread + join(timeout)" cannot work. Instead the step runs in the calling thread and a timer thread cancels the in-flight request on the Playwright asyncio loop (`call_soon_threadsafe`, cancelling every task except `Connection.run_as_sync`). Live probe with a real headless Chromium (scratchpad `thr2.py`, `live.py`): an 8 s `wait_for_timeout` was cancelled at 3.0 s and the connection stayed usable; through `close_session(timeout_s=2.0)` a hung request returned after 2.0 s with phase `session_close.context ok=False note="abandoned after 2s"`, and a real `ctx.close()` + `pw.stop()` afterwards took 0.6 s. No process is killed (B9 untouched).
