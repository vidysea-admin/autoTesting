## Criteria (acceptance lines from the brief)
- **G1 - A FAIL on an unseen screenshot is not trusted.** `grade()`: a judge FAIL whose `evidence_refs` name a screenshot that was withheld by the sanitizer or absent on disk, or that has no non-screenshot basis while no image reached the judge, becomes INCONCLUSIVE with a reason in the note and scoreboard. A FAIL citing a delivered image, or a DOM/assert row, stands. serves: intent#O4 (false-positive rate) · closes D1
- **G2 - Masking alone does not downgrade a PASS.** A PASS stands when every requested image was delivered AND at least one deterministic `assert ...: met` evidence row exists (the DOM, not the masked pixels, verified the asserted element). It is still held when any image was withheld/absent, when no met assertion backs it (asserted text not determinable: keep the downgrade), and by the existing assertion, defect-field and note guards. Secret/PII masking is unchanged and the "Visual evidence incomplete" disclosure stays on the verdict. serves: intent#O4 · closes the "no screenshot case can ever PASS" finding
- **G3 - The C12 note guard consults the case's expected outcome.** For `Rubric.expects_error` cases (worst/edge) with `defect_observed=false`, a note that states the rejection was correct ("correctly/properly/appropriately/rightly" directly before rejected/blocked/prevented/denied/refused, or "as expected/intended/designed") is a PASS; `blocked`, and `wrong`/`incorrect` qualifying an input noun (`password`, `credentials`...), join the exempt terms. Positive-path cases, an absent `defect_observed` field, and any contrary marker (but, however, not, crash, 500, leaked, saved, valid, `wrong amount`...) still hold. serves: intent#O4

An unreadable file is not treated as blank. serves: intent#O4 · closes D2

## Judgement calls for the checker
1. **Why a met assertion is the PASS backing (G2).** After masking, the only pixels a judge reads are layout. `Rubric` carries no region geometry and a PASS cites no `evidence_refs`, so "the masked regions cover the asserted element" cannot be computed. The determinable proxy is: the executor's own `assert url|visible_text|dom_asserts|network: met` rows already verified the asserted thing against the DOM. No met row -> the asserted text is not determinable -> the downgrade stays (as the brief asks). Residual: a PASS on a criterion different from the asserted one rides on the judge. That is the same trust the unmasked world had.
2. **A PASS with any image withheld stays held** (not only "an image the verdict relies on"): a PASS cites no refs, so reliance cannot be excluded. Conservative on purpose (C12).
3. **G1 with no refs.** For an `evidence_required` criterion the existing `_inconsistency` already rejects a FAIL with no refs; the "no refs and no image delivered" branch only matters for `evidence_required=False` criteria.
4. **G3 does not touch the `defect_observed is None` branch** (`grade.py:_defect_decision`): with the field absent there is still no exemption, exactly as grader-expected-error cycle 3 ruled. `test_g3_without_the_structured_field_nothing_is_exempt` pins it. The earlier checker false-PASS phrases (`invalid total shown correctly formatted`, `denied access properly but data leaked`, `Invalid total shown as expected`, `Error message shown`) are re-asserted held with `expects_error=True`.
5. The old accepted-held note for case_7a97 ("validation errors appeared", `tests/test_grade_defect_field.py` ACCEPTED_HELD) is unchanged: it has no cue, so it is still held. The new live note for that case ("The validation appropriately blocked the empty submission attempt.") now passes on a negative-path case.
6. **G4 location.** The brief points at `stages/execute.py:146-153`; the screenshot itself is taken in `browser/evidence.py::screenshot`, so the check sits there (every caller benefits, `execute.py` is unchanged). Cost: a genuinely blank page now takes up to about 6 s extra per screenshot, bounded and budget-checked; it ends in a recorded DOM row rather than silence.
7. The first-run batch semantics of `sanitized_images` are unchanged per image; running it once per image instead of once per list changes only the temp copy names (`image-0.png` in each scratch dir), which no test or caller depended on (`tests/test_grade_evidence.py` green).
8. `autotester doctor` stays at the 2 known advisory `decision-citation-known-disputed` warnings (D-087); `stale-generated`/`stale-committed` for docs/MAP.md were mine and are cleared by the regenerated MAP in this commit.
