## Deliberate gaps (the checker should read these)
1. **No production caller yet.** `run_ux_advisory` is not called from any route. The hook belongs in `ui/routes_runs.py::trigger_run` after functional results and verdicts persist (T-125 owns that file): `run_ux_advisory(store, run.id, judge)` inside a try/except that logs and never aborts reporting. Exact line deferred, not edited.
2. **Budget is a logical call cap** (failed attempts counted), not the physical HTTP-attempt budget in the plan proposal. That needs `providers/*`, which is outside this unit's ownership. It is not a money or token ceiling; the field description says so.
3. **PU8 uses `Case.case_class` and `RawResult.outcome`**, not measured `ExecutionConditions` (the plan's `schema/run.py` + `execute.py` capture). Locale rule is an assumption: language `en` makes no locale claim, any other language needs a `LOCALE_I18N` case that did not end `NOT_RUN` (today none can complete, since `browser/conditions.py` cannot enact a locale). Device: `mobile/phone/tablet/android/iphone` claims `VIEWPORT_MOBILE`, `desktop/laptop` claims the default viewport, anything else is refused.
4. Payload bounds are constants (`MAX_IMAGES=4`, `MAX_EVIDENCE_LINES=40`), unreviewed numbers. No re-attempt/resume of a partial report. Mini-grill and the `docs/features/` entry not done.
5. PU3 test freezes `created_at` and `duration_s` (wall-clock mint values) before comparing; every other field and both stored files are byte-compared.
